API

Use PhishGuard from your own scripts, mail servers or apps. Everything you scan this way lands in the same database and history.

Your API key

{{ key }}

Send it in an X-API-Key header. Keep it private.

Scan an email

curl -X POST {{ base }}/api/v1/scan \
  -H "X-API-Key: {{ key }}" -H "Content-Type: application/json" \
  -d '{"sender":"PayPal <help@paypal-secure.xyz>","subject":"Account suspended","body":"Verify now: http://192.168.4.7/login"}'

Returns verdict, score, reasons, urls and the saved id. Add "save": false to skip storing it.

Python example

import requests
r = requests.post("{{ base }}/api/v1/scan", headers={"X-API-Key": "{{ key }}"},
                  json={"sender": "a@b.com", "subject": "Hi", "body": "Meeting at 3?"})
print(r.json()["verdict"], r.json()["score"])

Endpoints

MethodPathWhat it does
GET/api/v1/healthStatus check (no key needed)
POST/api/v1/scanScan an email: sender, subject, body
POST/api/v1/check-urlCheck a single link: {"url": "https://..."}
GET/api/v1/scansList history (?q=, ?verdict=, ?limit=)
GET/api/v1/scans/<id>One scan with full details
GET/api/v1/statsTotals and 7-day activity
